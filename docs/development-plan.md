# 独立 Seller ID 采集版本开发计划

## 目标

建立与原店铺 ASIN 项目隔离的 UK Seller ID 采集项目。输入为 `UK店铺库-中国地址.xlsx` 的“卖家数据”B 列超链接，后续代码、配置、运行数据和 Git 版本独立维护。

## 已实施合同

1. B 列优先解析超链接目标中的 `me` 或 `seller` 参数，也接受直接 Seller ID 和 Amazon UK 卖家链接；按首次出现行去重，错误包含源行号。
2. 初筛保留价格 £6.99–£50.00，并按字段放行 NA：评分为空或至少 3.5，评论数为空或不超过 300。
3. 历史数据库阶段固定跳过并记录事件。新 run 使用 SQLite schema v15；旧 schema 只能只读审计。
4. SellerSprite 补全后保留 FBA、变体数不超过 3、上架 0–180 天。子体销量不再分段筛选。
5. 所有合格产品都请求七天销量接口，固定每日最低销量 3；只接受精确 `yes` 或 `No`，接口或协议错误暂停任务并保留进度。
6. Excel 保留 19 列，输出 `0-30天`、`31-180天` 和 `产品数据` 三张表。评分或评论 NA 在 Excel 显示为 `NA`。

## 实现边界

店铺分页、同店铺去重、跨店铺候选去重、浏览器恢复、代理协调、SellerSprite 两轮补全、详情补全和运行账本复用已验证实现。新项目通过 `stores.proxyControllerPath` 指向共享 UK 代理控制器，不复制控制器代码。测试使用临时 Excel、SQLite 和模拟 MCP，正式全量任务必须由操作者单独启动。

## 验证

类型检查、离线测试、B 列解析、NA 初筛、180 天边界、全量销量任务、断点续跑、v15 数据库和三张表结构均纳入测试。真实 Amazon、SellerSprite、代理和全量卖家库验收单独记录，不能由离线测试或 `/healthz` 结论替代。
